# Liltoon UnityGLTF 扩展开发说明

这个仓库是一个独立 Unity Package。它不是 UnityGLTF fork，而是在 UnityGLTF 导入流程里接住 Hollow/lil 系列自己的 glTF 材质契约。

## 为什么做这个包

UnityGLTF 默认会把 glTF 材质导成自己的 PBRGraph 材质。导入完成后再右键转换到 URP/Lit 或 lilToon，只能读取已经写进 `.mat` 的 Unity shader property。

如果 glTF 里有自定义材质契约，例如：

```text
material.extensions.HO_materials_principled_lil
```

普通 `.mat` 转换器看不到这段原始 JSON。这个包把转换入口前移到 UnityGLTF import plugin，让我们在 `GLTFMaterial.Extensions` 还存在时读取并保存契约。

## 当前实现

插件入口：

```text
Runtime/HoMaterialsPrincipledLilImport.cs
```

它继承：

```csharp
UnityGLTF.Plugins.GLTFImportPlugin
```

UnityGLTF 会自动扫描所有程序集里的 import plugin，并把它显示在：

```text
Project Settings > UnityGLTF > Import > Import Extensions and Plugins
```

当前插件显示名：

```text
HO_materials_principled_lil
```

目前做了四件事：

1. 检查 `HO_materials_principled_lil`，并兼容旧名 `HO_materials_openpbr_lil`。
2. 把原始 extension JSON 保存成 `HoMaterialContractAsset` 子资源。
3. 解析 Blender 侧 `HoGLTF` 自定义节点组写出的 `hogltf.inputs` / `hogltf.sockets`。
4. 提供临时的 `applyUrpLitFallback`，把 UnityGLTF/PBRGraph 风格属性切到 URP/Lit。

第四步只是过渡口。最终目标是直接把契约映射到 lilToon 或 lilPBR。

调试接口时，`HoMaterialContractAsset` 默认不隐藏。导入 glTF 后，可以直接在 Unity 的资源层级里点开子资源查看 `HoGltfInputs`。如果项目里觉得子资源太多，可以在 UnityGLTF 插件设置里打开 `hideContractSubAssets`。

## 重要结论

UnityGLTF/GLTFSerialization 会把未知 extension 反序列化成 `DefaultExtension` 并保留原始 JSON，所以第一版不需要先写 typed extension factory。

只要 glTF 材质里带有：

```json
"extensions": {
  "HO_materials_principled_lil": {}
}
```

UnityGLTF 反序列化后，插件就可以从 `GLTFMaterial.Extensions` 里取到它。

以后如果要做强类型解析，再添加自己的 factory 和 contract model。

## 下一步怎么写

建议保持 plugin 入口稳定，把真正的材质映射拆出去：

```text
Runtime/
  HoMaterialsPrincipledLilImport.cs
  HoMaterialContractAsset.cs
  HoMaterialContractParser.cs
  Mapping/
    HoContractReader.cs
    HoTextureResolver.cs
    LilToonMaterialMapper.cs
    LilPbrMaterialMapper.cs
    UrpLitMaterialMapper.cs
```

推荐策略：

1. `target.shaderFamily == lilToon` 时直接生成 lilToon 材质。
2. `target.shaderFamily == lilPBR` 时直接生成 lilPBR 材质。
3. `target.shaderFamily == auto` 时，看 `toon` block 是否启用风格化；启用则 lilToon，否则 lilPBR。
4. 如果目标 shader 不存在，只保存契约，不破坏 UnityGLTF 默认材质。

不要从 PBRGraph 反推自定义材质含义。只要 contract 存在，它就是 source of truth。

## 项目里怎么拉包

在项目 `Packages/manifest.json` 里同时放 UnityGLTF 和这个包：

```json
{
  "dependencies": {
    "org.khronos.unitygltf": "https://github.com/KhronosGroup/UnityGLTF.git",
    "jp.lilxyzw.liltoon.unitygltf.extensions": "file:D:/Unity_Fork/Liltoon-UnityGLTF-Extensions"
  }
}
```

如果使用 Package Manager UI，先添加 UnityGLTF，再添加本地包：

