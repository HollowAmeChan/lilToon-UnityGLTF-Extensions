# 材质契约计划

这个包是材质契约的 Unity 导入侧实现。契约源头参考：

```text
D:/Unity_Fork/lilToon/接口契约.md
```

契约围绕 Blender Principled BSDF 数据设计，同时预留 OpenPBR 兼容字段和 lilToon/lilPBR 项目扩展。

## Extension 名称

主名称：

```text
HO_materials_principled_lil
```

旧名兼容：

```text
HO_materials_openpbr_lil
```

## 第一阶段稳定导入范围

第一版生产 importer 建议支持：

- `principled.baseColor.factor`
- `principled.baseColor.texture`
- `principled.metallic.factor`
- `principled.roughness.factor`
- `principled.normal.texture`
- `principled.normal.scale`
- `principled.emission.color`
- `principled.emission.strength`
- `principled.alpha`
- `principled.alphaMode`
- `principled.alphaCutoff`
- `principled.geometry.occlusion`
- `principled.geometry.height`
- `principled.packed.preset = ORM`
- `principled.packed.texture`
- `toon.shadow`
- `toon.rim`
- `toon.outline`
- `unity.doubleSided`
- `unity.renderQueue`
- `hogltf.inputs`
- `hogltf.sockets`

## 映射规则

通用规则：

- 契约里的 roughness 保持外部标准值。
- 写入 Unity 材质时用 `smoothness = 1 - roughness`。
- base color 和 emission 纹理按 sRGB 处理。
- roughness、metallic、AO、height、mask 纹理按 linear 处理。
- normal 纹理按 normal map 处理。

目标选择：

- 显式 `target.shaderFamily` 优先。
- `toon.mode == toon`、outline、shadow、rim 等提示应选择 lilToon。
- 其他情况优先 lilPBR。

暂不支持的数据：

- 保留 unsupported OpenPBR 字段到元数据。
- 不把 clear coat 硬伪装成 MatCap。
- 不把 transmission 硬伪装成普通 alpha。
- 不把 fuzz/sheen 硬伪装成 rim，除非 `toon` block 明确要求。

## Blender HoGLTF 节点组

Blender 侧会读取名为 `HoGLTF` 的自定义节点组，把输入写进：

```text
HO_materials_principled_lil.hogltf.inputs
HO_materials_principled_lil.hogltf.sockets
```

Unity 侧当前会解析这些字段，并保存到 `HoMaterialContractAsset.HoGltfInputs`。

后续可以按输入名建立映射表，例如：

```text
Param1 -> 某个 lilToon/lilPBR shader property
```

## 为什么不从 PBRGraph 转换

UnityGLTF 默认导入路径适合通用 glTF 往返，但项目契约包含很多没有 PBRGraph 等价 property 的信息。

这些信息一旦在导入阶段被忽略，后续 `.mat` 转换器就无法恢复。

因此 importer 必须在 glTF extension 还存在时读取契约。
